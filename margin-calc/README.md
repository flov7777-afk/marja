# Калькулятор маржи для Wildberries и Ozon

Готовый к публикации статический сайт: обычный светлый дизайн, калькулятор в виде переиспользуемого веб-компонента, четыре SEO-страницы, метаданные, sitemap и конфиги для хостингов. Без сборки и бэкенда.

## Состав

```text
margin-calc/
├─ index.html                  главная
├─ 404.html
├─ favicon.svg
├─ og-image.svg                картинка для соцсетей
├─ robots.txt
├─ sitemap.xml
├─ netlify.toml
├─ vercel.json
├─ .nojekyll
├─ css/style.css
├─ js/
│  ├─ app.js                   веб-компонент <margin-calculator>
│  ├─ meta.js                  динамический canonical и og:url
│  └─ telegram.js              поддержка Telegram Mini App
├─ wildberries/index.html      SEO: калькулятор маржи Wildberries
├─ ozon/index.html             SEO: калькулятор маржи Ozon
├─ unit-economics/index.html   SEO: юнит-экономика маркетплейса
├─ breakeven/index.html        SEO: цена безубыточности
├─ posts.md                    5 готовых постов для раскрутки
└─ telegram-setup.md            как открыть как Telegram Mini App
```

## Локальный запуск

```bash
cd margin-calc
python -m http.server 5191 --bind 127.0.0.1
```

Откройте <http://127.0.0.1:5191/>. Можно открыть `index.html` напрямую.

## Что умеет

- Вкладки Wildberries / Ozon / Свои условия с подстановкой тарифов.
- Все параметры редактируются: цена, себестоимость, комиссия, логистика, скидка, возвраты, потери на возврат, прочие расходы.
- Прибыль, маржа, цена после скидки, цена безубыточности.
- Разбивка расходов, три примера товаров, сброс.
- «Скопировать расчёт» и «Поделиться ссылкой» — параметры хранятся в URL.
- Динамический `canonical` и `og:url` — не нужно править домен в HTML.
- Бесплатный шрифт **Manrope** с кириллицей (Google Fonts, с системным fallback).
- Аккуратная подпись **@merzter** в шапке, футере и OG-картинке — ссылка на `t.me/merzter`.
- JSON-LD (`WebApplication` на главной, `FAQPage` на SEO-страницах).
- Готовность к **Telegram Mini App**: тема Telegram, нижняя кнопка, «Назад», вибрация, Sharing и `startapp`.
- Адаптив, доступные подписи, `prefers-reduced-motion`.

## Формула

```text
цена после скидки = цена × (1 − скидка)
комиссия = цена после скидки × комиссия%
потери от возвратов = доля возвратов × потери на один возврат
прибыль = цена после скидки − комиссия − себестоимость − логистика − потери от возвратов − прочие
цена безубыточности = постоянные расходы / ((1 − комиссия) × (1 − скидка))
```

Тарифы по умолчанию — в объекте `MARKETS` в `js/app.js`. Перед публикацией подставьте актуальные.

## Публикация

### Netlify / Vercel / Cloudflare Pages

1. Залейте содержимое папки `margin-calc` в репозиторий.
2. Netlify: репозиторий подключается как есть, `netlify.toml` уже задаёт publish directory `.`.
3. Vercel: просто импортируйте репозиторий — `vercel.json` включит чистые URL.
4. GitHub Pages: включите Pages из ветки `main`, корень `/` — файл `.nojekyll` уже есть.

### Обязательно перед выкладыванием

1. Замените `https://example.com` на свой домен в `sitemap.xml` и `robots.txt`.
2. Проверьте тарифы в `js/app.js` (`MARKETS`) и цифры в `posts.md`.
3. Залейте `og-image.svg` — уже лежит в корне, путь в метатегах абсолютный `/og-image.svg`.
4. При желании добавьте Яндекс.Метрику в `<head>` всех страниц.
5. Проверьте пять URL: `/`, `/wildberries/`, `/ozon/`, `/unit-economics/`, `/breakeven/`.

### Telegram

Чтобы открыть калькулятор как Telegram Mini App, следуйте [`telegram-setup.md`](telegram-setup.md): создайте бота через @BotFather и отправьте одну команду с кнопкой `web_app`. Бэкенд не требуется. Обычный сайт и все OG-метатеги продолжают работать так же.
